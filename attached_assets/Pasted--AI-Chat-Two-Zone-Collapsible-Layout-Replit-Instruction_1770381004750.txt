# AI Chat Two-Zone Collapsible Layout — Replit Instruction (v5)

> **This replaces Doc 26-v4.** Fundamental shift: from open vertical timeline to **two contained zones with accordion-style collapsibility**. The entire execution of a complex task should NOT make the chat scroll endlessly.

---

## Problem with v4 (current implementation)

The UnifiedTimeline approach still makes the chat **too long** for complex tasks:

1. **Open timeline = unbounded height**: Every step's content (L1/L2/L3) expands the timeline vertically. A 5-step task with insights and process details creates a very tall block.
2. **No containment**: The timeline flows openly in the chat — there's no visual boundary telling the user "this is one task execution."
3. **No collapse at the step level**: Done steps still show their L2/L1 content inline, consuming vertical space even when the user has moved past them.
4. **Missing intent recognition zone**: The user's request goes straight to execution. There's no distinct "I understood your request, here's my plan" moment before execution begins.

## Solution: Two-Zone Collapsible Cards

The entire AI response to a complex task is organized into **two distinct zones (cards)**:

| Zone | Purpose | Default State |
|------|---------|---------------|
| **Zone 1: IntentPlanCard** | Shows intent recognition + task plan | Expanded (compact) |
| **Zone 2: ExecutionCard** | Contains ALL execution steps as accordion sections | Active step expanded, completed steps collapsed |

**Key principle: a complex 5-step task should occupy roughly the same vertical space as 2-3 normal chat messages.** Users expand sections on demand.

---

## What Changed from v4

| v4 (current) | v5 (this update) |
|--------------|-------------------|
| UnifiedTimeline — open vertical timeline | **Two contained cards** with clear boundaries |
| Timeline grows unbounded as steps execute | **Fixed-height feel** — completed steps auto-collapse |
| No intent recognition zone | **IntentPlanCard** shows understanding + plan |
| Progress header "Progress ——— 2/5" | **ExecutionCard header** shows active step name + progress |
| Done steps show all content inline | Done steps **collapse to one-line summary**, click to expand |
| 5 components | **4 components** (IntentPlanCard, ExecutionCard, ResultHighlight, ChatMessageList) |

**What stays the same:** Data model (taskPlanStepId), L1/L2/L3 message levels, interaction model, Agent roles + colors, mock data structure.

---

## Interaction Model (unchanged)

Upliftly is a **task-execution Agent**. User sends ONE complex request → Agent auto-decomposes → auto-executes all steps → user intervenes only when needed.

## Component 1: IntentPlanCard (Zone 1 — NEW)

This card appears immediately after the user's message. It shows two things:
1. **Intent recognition**: A brief sentence confirming what the Agent understood
2. **Task plan**: The list of steps the Agent will execute

This is a **contained card** with a subtle border. It does NOT expand — it's always compact.

```jsx
function IntentPlanCard({ intentSummary, steps }) {
  const doneCount = steps.filter((s) => s.status === "done").length;
  const activeStep = steps.find((s) => s.status === "active");

  const agentIcons = {
    scout: "🕵️", capturer: "📸", analyst: "📊",
    comparator: "⚖️", reporter: "📝",
  };

  return (
    <div className="mx-1 mt-3 rounded-xl border border-border/15
      bg-muted/5 overflow-hidden">
      {/* Header */}
      <div className="px-4 py-3 border-b border-border/10">
        <p className="text-sm text-foreground/90 leading-relaxed">
          {intentSummary}
        </p>
      </div>

      {/* Step list — always visible, very compact */}
      <div className="px-4 py-3 space-y-1.5">
        {steps.map((step) => {
          const icon = agentIcons[step.agentRole] || "🤖";
          return (
            <div key={step.id}
              className="flex items-center gap-2 text-xs">
              {/* Status indicator */}
              <span className={`shrink-0 ${
                step.status === "done"
                  ? "text-muted-foreground/40"
                  : step.status === "active"
                  ? "text-blue-400"
                  : "text-muted-foreground/25"
              }`}>
                {step.status === "done" ? "✓" :
                 step.status === "active" ? "●" : "○"}
              </span>
              {/* Agent icon + label */}
              <span className={`${
                step.status === "done"
                  ? "text-muted-foreground/40 line-through"
                  : step.status === "active"
                  ? "text-foreground font-medium"
                  : "text-muted-foreground/30"
              }`}>
                {icon} {step.label}
              </span>
            </div>
          );
        })}
      </div>

      {/* Footer: progress bar */}
      <div className="px-4 pb-3">
        <div className="h-1 rounded-full bg-border/10 overflow-hidden">
          <div
            className="h-full rounded-full bg-blue-400/60
              transition-all duration-500"
            style={{
              width: `${(doneCount / steps.length) * 100}%`
            }}
          />
        </div>
      </div>
    </div>
  );
}
```

**Key visual traits:**
- **Contained card**: `rounded-xl border border-border/15` — clear visual boundary
- **Intent summary at top**: Confirms understanding before showing plan
- **Compact step list**: Each step is one line with `✓/●/○` + agent icon + label
- **Done steps get strikethrough**: `line-through` makes completed steps visually recede
- **Thin progress bar at bottom**: Shows overall completion without taking space
- **No expand/collapse needed**: This card is always small enough to show fully

## Component 2: ExecutionCard (Zone 2 — NEW, core component)

This is the **main innovation**. The entire execution process lives inside ONE contained card. Each step is an **accordion section** that can be expanded/collapsed.

**Behavior rules:**
- **Active step**: Always expanded, shows live progress
- **Completed steps**: Auto-collapse to a one-line summary. User clicks to expand.
- **Pending steps**: Not shown inside the card (they're already visible in IntentPlanCard)
- **Card header**: Shows the currently active step name + overall progress count

```jsx
function ExecutionCard({ steps, stepMessages }) {
  const [expandedSteps, setExpandedSteps] = React.useState(new Set());
  const doneCount = steps.filter((s) => s.status === "done").length;
  const activeStep = steps.find((s) => s.status === "active");
  const doneAndActiveSteps = steps.filter(
    (s) => s.status === "done" || s.status === "active"
  );

  const agentIcons = {
    scout: "🕵️", capturer: "📸", analyst: "📊",
    comparator: "⚖️", reporter: "📝",
  };

  const agentColors = {
    scout: "text-blue-400",
    capturer: "text-purple-400",
    analyst: "text-orange-400",
    comparator: "text-green-400",
    reporter: "text-pink-400",
  };

  const toggleStep = (stepId) => {
    setExpandedSteps((prev) => {
      const next = new Set(prev);
      if (next.has(stepId)) next.delete(stepId);
      else next.add(stepId);
      return next;
    });
  };

  // Determine if a step should show expanded content
  const isExpanded = (step) => {
    if (step.status === "active") return true; // always expanded
    return expandedSteps.has(step.id); // user toggled
  };

  return (
    <div className="mx-1 mt-2 rounded-xl border border-border/15
      bg-muted/5 overflow-hidden">

      {/* ── Card Header: active step name + progress ── */}
      <div className="flex items-center justify-between px-4 py-2.5
        border-b border-border/10">
        <div className="flex items-center gap-2 min-w-0">
          {activeStep ? (
            <>
              <span className="relative flex h-2 w-2 shrink-0">
                <span className="animate-ping absolute inline-flex
                  h-full w-full rounded-full bg-blue-400 opacity-75" />
                <span className="relative inline-flex rounded-full
                  h-2 w-2 bg-blue-400" />
              </span>
              <span className="text-xs text-foreground/80 truncate">
                {agentIcons[activeStep.agentRole]}{" "}
                {activeStep.label}
              </span>
            </>
          ) : (
            <span className="text-xs text-muted-foreground/50">
              ✓ All steps completed
            </span>
          )}
        </div>
        <span className="text-[10px] text-muted-foreground/40
          tabular-nums shrink-0 ml-3">
          {doneCount}/{steps.length}
        </span>
      </div>

      {/* ── Accordion sections: done + active steps ── */}
      <div className="divide-y divide-border/8">
        {doneAndActiveSteps.map((step) => {
          const msgs = stepMessages[step.id] || [];
          const icon = agentIcons[step.agentRole] || "🤖";
          const color = agentColors[step.agentRole] || "";
          const expanded = isExpanded(step);
          const hasInsight = msgs.some(
            (m) => m.messageLevel === "insight" || m.canvasLinkId
          );

          return (
            <div key={step.id}>
              {/* ── Accordion header (clickable for done steps) ── */}
              <button
                onClick={() => step.status === "done" && toggleStep(step.id)}
                className={`w-full flex items-center gap-2 px-4 py-2
                  text-left transition-colors ${
                  step.status === "done"
                    ? "hover:bg-muted/8 cursor-pointer"
                    : "cursor-default"
                }`}
              >
                {/* Expand/collapse chevron (done steps only) */}
                {step.status === "done" ? (
                  <span className="text-[10px] text-muted-foreground/30
                    shrink-0 w-3">
                    {expanded ? "▾" : "▸"}
                  </span>
                ) : (
                  <span className="shrink-0 w-3" />
                )}

                {/* Step status + label */}
                <span className={`text-xs ${
                  step.status === "done"
                    ? "text-muted-foreground/40"
                    : "text-foreground"
                }`}>
                  {step.status === "done" ? "✓" : "●"}{" "}
                  {icon} {step.label}
                </span>

                {/* Collapsed summary for done steps */}
                {step.status === "done" && !expanded && step.summary && (
                  <span className="text-[11px] text-muted-foreground/30
                    truncate ml-auto pl-2">
                    — {step.summary}
                  </span>
                )}

                {/* Insight badge for done steps with insights */}
                {step.status === "done" && !expanded && hasInsight && (
                  <span className={`text-[10px] ${color} opacity-50
                    shrink-0 ml-1`}>
                    ◆
                  </span>
                )}
              </button>

              {/* ── Expanded content ── */}
              {expanded && msgs.length > 0 && (
                <div className="px-4 pb-3 pt-0 ml-5">
                  <div className="space-y-1.5">
                    {renderStepContent(msgs)}
                  </div>
                </div>
              )}
            </div>
          );
        })}
      </div>
    </div>
  );
}
```

**Key visual traits:**
- **Contained card**: Same `rounded-xl border` as IntentPlanCard — the two zones look like siblings
- **Dynamic header**: Shows the ACTIVE step name with a pulsing dot + progress count. When all done, shows "✓ All steps completed"
- **Accordion sections**: Each completed step is a clickable row that expands/collapses
- **Collapsed done step**: Shows `▸ ✓ 🕵️ Browse competitor.com — Found 4 nav items ◆`
  - The `—` summary gives a quick result preview
  - The `◆` diamond badge indicates this step produced an Insight
- **Expanded done step**: Shows the full L1/L2/L3 content below the header
- **Active step**: Always expanded, no chevron (can't collapse)
- **Pending steps NOT shown here**: They're already in IntentPlanCard. No need to repeat.
- **`divide-y divide-border/8`**: Ultra-subtle dividers between accordion sections
- **Compact by default**: A 5-step task with 3 done + 1 active shows ~5 lines collapsed + active content

## Component 3: ResultHighlight (replaces InsightMessage inside execution)

When an L1 Insight appears inside the ExecutionCard, it's rendered as a **highlighted result card** with a colored accent. This is the "card结论摘要-可突出颜色展示" the user described.

```jsx
function ResultHighlight({ message }) {
  const accentColors = {
    scout: "border-blue-400/30 bg-blue-400/5",
    capturer: "border-purple-400/30 bg-purple-400/5",
    analyst: "border-orange-400/30 bg-orange-400/5",
    comparator: "border-green-400/30 bg-green-400/5",
    reporter: "border-pink-400/30 bg-pink-400/5",
  };

  const accent = accentColors[message.agentRole] || "border-border/20 bg-muted/5";

  return (
    <div className={`rounded-lg border-l-2 px-3 py-2.5 ${accent}`}>
      <div className="text-[13px] text-foreground/90 leading-relaxed">
        {message.content}
      </div>
      {message.canvasLinkId && (
        <div className="mt-2 flex items-center gap-1.5 text-[11px]
          text-primary/60 hover:text-primary cursor-pointer
          transition-colors">
          <span>📌</span>
          <span>→ {message.canvasCardTitle || "View in Canvas"}</span>
        </div>
      )}
    </div>
  );
}
```

**Key visual traits:**
- **Colored left border + tinted background**: `border-l-2 border-orange-400/30 bg-orange-400/5` — subtle but distinct from plain text
- **No agent label**: The parent accordion section already identifies the agent
- **Compact**: `text-[13px]` — slightly larger than process text but not full `text-sm`
- **Canvas link**: If the insight links to a Canvas card, show the link

## Helper: renderStepContent (renders L1/L2/L3 inside accordion)

This helper renders the messages belonging to a step inside the expanded accordion section.

```jsx
function renderStepContent(msgs) {
  const rendered = [];
  let i = 0;

  while (i < msgs.length) {
    const msg = msgs[i];
    const level = msg.messageLevel || getDefaultLevel(msg);

    if (level === "insight") {
      // L1: ResultHighlight card
      rendered.push(
        <ResultHighlight key={msg.id} message={msg} />
      );
      i++;
    } else if (level === "progress") {
      // L2: Simple one-line text
      rendered.push(
        <div key={msg.id} className="py-0.5">
          <span className="text-[11px] text-muted-foreground/50
            leading-relaxed">
            {msg.content}
          </span>
        </div>
      );
      i++;
    } else {
      // L3: Collapsible process steps
      const group = [msg];
      while (
        i + 1 < msgs.length &&
        (msgs[i + 1].messageLevel || getDefaultLevel(msgs[i + 1]))
          === "process"
      ) {
        i++;
        group.push(msgs[i]);
      }
      rendered.push(
        <ProcessSteps key={`proc-${msg.id}`} messages={group} />
      );
      i++;
    }
  }

  return rendered;
}

// L3 process steps — collapsible micro-steps
function ProcessSteps({ messages }) {
  const [isExpanded, setIsExpanded] = React.useState(false);

  const hasActive = messages.some(
    (m) => m.thoughtProcess?.steps?.some((s) => s.status === "active")
  );
  const allSteps = messages.flatMap(
    (m) => m.thoughtProcess?.steps || []
  );
  const expanded = isExpanded || hasActive;
  const doneSteps = allSteps.filter((s) => s.status === "done").length;

  return (
    <div className="py-0.5">
      <button
        onClick={() => setIsExpanded(!isExpanded)}
        className="flex items-center gap-1.5 text-[10px]
          text-muted-foreground/35 hover:text-muted-foreground/50
          transition-colors"
      >
        <span>{expanded ? "▾" : "▸"}</span>
        <span>
          {hasActive
            ? "working..."
            : `${doneSteps} step${doneSteps !== 1 ? "s" : ""} completed`}
        </span>
      </button>

      {expanded && (
        <div className="mt-1 ml-2 space-y-0.5">
          {allSteps.map((step, i) => (
            <div key={i} className="flex items-center gap-1.5
              text-[10px] text-muted-foreground/35">
              <span className={`w-1 h-1 rounded-full shrink-0 ${
                step.status === "done"
                  ? "bg-muted-foreground/20"
                  : step.status === "active"
                  ? "bg-blue-400 animate-pulse"
                  : "bg-muted-foreground/10"
              }`} />
              <span>{step.label}</span>
            </div>
          ))}
        </div>
      )}
    </div>
  );
}

function getDefaultLevel(msg) {
  if (msg.taskPlan) return "plan";
  if (msg.canvasLinkId) return "insight";
  if (["analyst", "comparator", "reporter"].includes(msg.agentRole)) {
    return "insight";
  }
  if (msg.thoughtProcess) return "process";
  return "progress";
}
```

## Component 4: ChatMessageList (REWRITTEN for two-zone layout)

```jsx
function ChatMessageList({ messages }) {
  const taskPlanMsg = messages.find((m) => m.taskPlan);
  const taskPlanSteps = taskPlanMsg?.taskPlan || [];
  const intentSummary = taskPlanMsg?.intentSummary
    || taskPlanMsg?.content || "";

  // Group messages by taskPlanStepId
  const stepMessages = {};
  taskPlanSteps.forEach((step) => {
    stepMessages[step.id] = [];
  });

  const preFlowMessages = []; // greeting, user message

  messages.forEach((msg) => {
    if (msg.taskPlan || msg.role === "user" ||
        (!msg.taskPlanStepId && !taskPlanMsg)) {
      preFlowMessages.push(msg);
    } else if (msg.taskPlanStepId && stepMessages[msg.taskPlanStepId]) {
      stepMessages[msg.taskPlanStepId].push(msg);
    }
  });

  const hasExecution = taskPlanSteps.some(
    (s) => s.status === "done" || s.status === "active"
  );

  return (
    <div className="flex flex-col gap-0.5">
      {/* Pre-flow: greeting + user request */}
      {preFlowMessages.map((msg) => {
        if (msg.role === "user") {
          return (
            <div key={msg.id} className="flex justify-end px-4 py-2">
              <div className="max-w-[80%] rounded-2xl px-4 py-2.5
                bg-primary/15 text-sm text-foreground leading-relaxed">
                {msg.content}
              </div>
            </div>
          );
        }
        if (msg.taskPlan) return null; // handled by zones
        // Greeting message (outside zones)
        return (
          <div key={msg.id} className="px-4 py-2">
            <div className="text-sm text-foreground/80 leading-relaxed">
              {msg.agentRole && <AgentLabel role={msg.agentRole} />}
              <span className="mt-1 block">{msg.content}</span>
            </div>
          </div>
        );
      })}

      {/* ═══ Zone 1: Intent + Plan ═══ */}
      {taskPlanSteps.length > 0 && (
        <IntentPlanCard
          intentSummary={intentSummary}
          steps={taskPlanSteps}
        />
      )}

      {/* ═══ Zone 2: Execution ═══ */}
      {hasExecution && (
        <ExecutionCard
          steps={taskPlanSteps}
          stepMessages={stepMessages}
        />
      )}
    </div>
  );
}
```

**Key change:** The message list now renders exactly **two zone components** after the user message. No open timeline, no unbounded vertical growth.

## AgentLabel utility (unchanged, used only for greeting)

```jsx
function AgentLabel({ role }) {
  const agents = {
    scout:      { icon: "🕵️", name: "Scout",      color: "text-blue-400" },
    capturer:   { icon: "📸", name: "Capturer",   color: "text-purple-400" },
    analyst:    { icon: "📊", name: "Analyst",    color: "text-orange-400" },
    comparator: { icon: "⚖️", name: "Comparator", color: "text-green-400" },
    reporter:   { icon: "📝", name: "Reporter",   color: "text-pink-400" },
  };
  const agent = agents[role] || agents.scout;
  return (
    <div className={`flex items-center gap-1.5 ${agent.color}`}>
      <span className="text-sm">{agent.icon}</span>
      <span className="text-xs font-semibold">{agent.name}</span>
    </div>
  );
}
```

## Design Principles (from competitive research — Doc 32)

This v5 design synthesizes insights from 7 EU/US AI agent products:

### 1. Containment over Open Flow
- **ChatGPT Deep Research**: Uses a contained progress area with collapsible steps — completed steps auto-fold to "▸ Searched 12 sources"
- **Perplexity Pro Search**: Step indicators are compact, contained at the top — not an open-ended timeline
- **v5 applies this**: Both zones are contained cards with clear boundaries. The execution doesn't bleed into the chat.

### 2. Collapse by Default, Expand on Demand
- **ChatGPT**: Tool call indicators auto-collapse after completion — `▸ Searching the web...` becomes a single line
- **Manus AI**: While using an open timeline, sub-results are inline and compact
- **v5 applies this**: Done steps collapse to one-line summaries. Only the active step is expanded. Users click to see details.

### 3. Process Light, Result Prominent
- **All 7 products**: Process steps use secondary styling (small, gray), results use primary styling (normal size, high contrast)
- **v5 applies this**: L3 process steps are `text-[10px] text-muted-foreground/35`. L1 ResultHighlight cards use colored borders + tinted backgrounds.

### 4. No Horizontal Dividers
- **All 7 products**: None use `──── LABEL ────` style phase dividers
- **v5 applies this**: Accordion sections use `divide-y divide-border/8` — ultra-subtle hairlines, not visual dividers.

### 5. Intent Before Execution
- **Perplexity Pro Search**: Shows "Step 1 of 4: Understanding the question" before executing
- **Devin AI**: Shows planning phase before coding
- **v5 applies this**: IntentPlanCard explicitly shows "I understood X, here's my plan" before ExecutionCard begins.

---

## Vertical Space Comparison

| Scenario | v4 (UnifiedTimeline) | v5 (Two-Zone Cards) |
|----------|---------------------|---------------------|
| 5 steps, 2 done, 1 active | ~35-40 lines | **~18-20 lines** |
| 5 steps, 4 done, 1 active | ~50-60 lines | **~20-22 lines** |
| 5 steps, all done | ~55-65 lines | **~15-17 lines** (all collapsed) |

The key savings come from:
- Done steps collapse to 1 line each (vs. showing all L1/L2/L3 content)
- Pending steps only appear in IntentPlanCard (not repeated in execution)
- No open timeline with connecting lines consuming vertical space

---

## What NOT to Do

- Do NOT render an open vertical timeline — use contained cards with accordion sections
- Do NOT show pending steps in the ExecutionCard — they're already in IntentPlanCard
- Do NOT expand completed steps by default — they must be collapsed
- Do NOT use connecting lines between steps — use `divide-y` hairlines instead
- Do NOT show Agent labels inside expanded step content — the accordion header already shows the agent
- Do NOT use horizontal dividers between zones
- Do NOT insert user messages between auto-executed steps
- Do NOT add real AI functionality — this is mock data only

---

## Acceptance Criteria

1. **Two distinct zones**: IntentPlanCard (Zone 1) and ExecutionCard (Zone 2) as sibling cards
2. **IntentPlanCard** shows intent summary text + compact step list with `✓/●/○` + progress bar
3. **ExecutionCard header** shows active step name with pulsing dot + `doneCount/totalCount`
4. **Done steps in ExecutionCard**: Collapsed to one line with `▸ ✓ icon label — summary ◆`
5. **Done steps expandable**: Click to reveal L1/L2/L3 content
6. **Active step**: Always expanded, shows live L3 process steps
7. **Pending steps**: Only in IntentPlanCard, NOT in ExecutionCard
8. **L1 ResultHighlight**: Colored left border + tinted background, no agent label
9. **L3 ProcessSteps**: Collapsible micro-steps with `text-[10px]`, auto-expand when active
10. **Vertical space**: A 5-step task with 2 done + 1 active should fit in ~20 lines
11. **Both cards use same visual style**: `rounded-xl border border-border/15 bg-muted/5`
12. **No open timeline**, no connecting lines, no unbounded vertical growth
13. **Dark theme consistent**
14. **Only 1 user message in demo**
15. **Greeting message outside zones** uses AgentLabel + plain text (no card)
16. **Insight badge `◆`** on collapsed done steps that contain L1 insights
