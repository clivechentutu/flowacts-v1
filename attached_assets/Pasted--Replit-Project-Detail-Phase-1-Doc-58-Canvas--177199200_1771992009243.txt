## 问题 1: Canvases 计数显示 (0)

### 现象

活容器项目和普通项目都显示 `Canvases (0)`，但页面上实际渲染了 2 张 Canvas 卡片。

### 原因

计数没有读取实际的 canvases 数组长度，可能硬编码了 0 或读取了错误的属性。

### 修正

找到 Canvases 区域的标题组件，确保计数使用实际数组长度：

```tsx
<h2 className="text-sm font-medium text-foreground">
  Canvases{' '}
  <span className="text-muted-foreground/50 font-normal">
    ({project.canvases.length})
  </span>
</h2>
```

检查数据源：如果 `project.canvases` 是 undefined，需要加兜底 `(project.canvases?.length ?? 0)`。

## 问题 2: Canvas 卡片底部信息布局错误

### 现象

Canvas 卡片底部的内容量指标、变化红点、更新日期三者的显示逻辑有误：

| 场景 | 期望 | 实际 |
|------|------|------|
| 活容器 + 有更新 (Brainstorming) | `5 cards · 12 shots` + 红点 + 日期 | `5 cards · 12 shots` + `● Updated`（**缺日期**） |
| 活容器 + 无更新 (Implementation Plan) | `2 cards · 0 shots` + 日期 | `2 cards · 0 shots` + `Updated 2/24`（✓） |
| 普通项目 + hasNewUpdates=true (Brainstorming) | `5 cards · 12 shots` + 日期 | `5 cards · 12 shots`（**缺日期**） |
| 普通项目 + 无更新 (Implementation Plan) | `2 cards · 0 shots` + 日期 | `2 cards · 0 shots` + `Updated 1/21`（✓） |

### 原因

红点和日期被实现为互斥的条件分支（if/else），导致：
- 显示红点时丢失日期
- 普通项目中 `hasNewUpdates=true` 的卡片两个分支都不匹配，什么都不显示

### 修正

将 Canvas 卡片底部改为两行布局，日期始终显示，红点作为日期的可选前缀：

```tsx
{/* 卡片底部信息区 */}

{/* 第一行：内容量指标（所有项目都显示） */}
<div className="text-xs text-muted-foreground/50">
  {canvas.cardCount} {canvas.cardCount === 1 ? 'card' : 'cards'} · {canvas.shotCount} {canvas.shotCount === 1 ? 'shot' : 'shots'}
</div>

{/* 第二行：更新日期（始终显示） + 可选红点前缀（仅活容器+有更新） */}
<div className="flex items-center gap-1.5 mt-1">
  {isActiveProject && canvas.hasNewUpdates && (
    <span className="w-1.5 h-1.5 rounded-full bg-red-500 shrink-0" />
  )}
  <span className={`text-xs ${
    isActiveProject && canvas.hasNewUpdates
      ? 'text-red-400'
      : 'text-muted-foreground/40'
  }`}>
    Updated {formatDate(canvas.updatedAt)}
  </span>
</div>
```

### 修正后效果

活容器项目 + 有更新的 Canvas：
```
5 cards · 12 shots
● Updated 2/24          ← 红点 + 红色日期
```

活容器项目 + 无更新 / 普通项目的所有 Canvas：
```
2 cards · 0 shots
Updated 1/21            ← 灰色日期，无红点
```

### 关键逻辑

- `Updated {date}` 始终渲染，不受任何条件控制
- 红点仅在 `isActiveProject && canvas.hasNewUpdates` 时渲染
- 有红点时日期文字变红（`text-red-400`），无红点时灰色（`text-muted-foreground/40`）
- 普通项目即使 mock 数据中 `hasNewUpdates=true`，因为 `isActiveProject=false`，红点不会显示，日期正常灰色

## 完整的 CanvasCard 组件参考

替换现有 Canvas 卡片组件的完整代码：

```tsx
function CanvasCard({
  canvas,
  isActiveProject,
}: {
  canvas: Canvas;
  isActiveProject: boolean;
}) {
  return (
    <div
      className="rounded-lg border border-border bg-card p-4
                 hover:border-primary/40 hover:shadow-sm
                 cursor-pointer transition-all"
      onClick={() => navigate(`/canvas/${canvas.id}`)}
    >
      {/* 标题 */}
      <div className="flex items-center gap-2 mb-2">
        <span className="text-sm">🎨</span>
        <h3 className="text-sm font-medium text-foreground truncate">
          {canvas.title}
        </h3>
      </div>

      {/* 描述 */}
      <p className="text-xs text-muted-foreground line-clamp-2 mb-3">
        {canvas.description}
      </p>

      {/* 内容量指标 — 所有项目都显示 */}
      <div className="text-xs text-muted-foreground/50">
        {canvas.cardCount} {canvas.cardCount === 1 ? 'card' : 'cards'} · {canvas.shotCount} {canvas.shotCount === 1 ? 'shot' : 'shots'}
      </div>

      {/* 更新日期 — 始终显示，红点为可选前缀 */}
      <div className="flex items-center gap-1.5 mt-1">
        {isActiveProject && canvas.hasNewUpdates && (
          <span className="w-1.5 h-1.5 rounded-full bg-red-500 shrink-0" />
        )}
        <span className={`text-xs ${
          isActiveProject && canvas.hasNewUpdates
            ? 'text-red-400'
            : 'text-muted-foreground/40'
        }`}>
          Updated {formatDate(canvas.updatedAt)}
        </span>
      </div>
    </div>
  );
}
```
