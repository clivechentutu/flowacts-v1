## 变更范围

1. **Project 卡片** — 去封面图，改为紧凑文字卡片

5. **Project Detail 页面** — 点击卡片后的详情页

不动的东西：左侧导航栏、顶部导航、创建项目入口和流程、任何业务逻辑/API 调用。

## 三、ProjectCard 组件改造

### 改前

当前卡片有封面图（`<img>` 或 `background-image`），占卡片 ~60% 面积。

### 改后

去掉封面图，改为纯文字卡片，三个区域：标题行、描述、底行。

### 具体操作

1. 找到 ProjectCard 组件
2. 删除封面图相关的整块 DOM（`<img>`、封面容器 `<div>` 等）
3. 替换卡片内容为以下结构：

```tsx
function ProjectCard({ project, onToggleFavorite }: {
  project: Project;
  onToggleFavorite: (id: string) => void;
}) {
  const navigate = useNavigate(); // or your routing method

  return (
    <div
      className="rounded-lg border border-border bg-card p-4
                 hover:border-primary/40 hover:shadow-sm
                 cursor-pointer transition-all"
      onClick={() => navigate(`/project/${project.id}`)}
    >
      {/* 标题行：脉搏灯(可选) + 标题 + 收藏星标 */}
      <div className="flex items-center gap-2 mb-2">
        {project.hasActiveContainer && (
          <span className="pulse-dot" />
        )}
        <h3 className="text-sm font-medium text-foreground truncate flex-1">
          {project.title}
        </h3>
        <button
          className={`shrink-0 text-sm transition-colors ${
            project.isFavorite
              ? 'text-yellow-400'
              : 'text-muted-foreground/30 hover:text-muted-foreground/60'
          }`}
          onClick={(e) => {
            e.stopPropagation();
            onToggleFavorite(project.id);
          }}
          aria-label={project.isFavorite ? 'Remove from favorites' : 'Add to favorites'}
        >
          {project.isFavorite ? '★' : '☆'}
        </button>
      </div>

      {/* 描述：最多 2 行，溢出截断 */}
      <p className="text-xs text-muted-foreground line-clamp-2 mb-3">
        {project.description}
      </p>

      {/* 底行：协同人数 · Canvas 数量 · 更新日期 */}
      <div className="text-xs text-muted-foreground/60">
        👤 {project.memberCount} · {project.canvasCount}{' '}
        {project.canvasCount === 1 ? 'canvas' : 'canvases'} ·{' '}
        {formatDate(project.updatedAt)}
      </div>
    </div>
  );
}
```

### 日期格式化

```typescript
function formatDate(date: Date | string): string {
  const d = new Date(date);
  const now = new Date();
  const month = d.getMonth() + 1;
  const day = d.getDate();

  if (d.getFullYear() === now.getFullYear()) {
    return `${month}/${day}`;          // 当年：2/20
  }
  const year = d.getFullYear() % 100;
  return `${month}/${day}/${year}`;    // 跨年：2/20/25
}
```

### 注意

- 活容器项目：标题前显示绿色脉搏灯（`.pulse-dot`）
- 普通项目：标题前无任何图标，直接显示标题
- 收藏星标常驻显示（不是 hover 才出现）
- 点击星标不触发卡片导航（`e.stopPropagation()`）

## 五、排序与筛选

### 默认排序

全量列表按最后更新时间降序。收藏不影响排序位置。

```typescript
function sortProjects(projects: Project[]): Project[] {
  return [...projects].sort((a, b) =>
    new Date(b.updatedAt).getTime() - new Date(a.updatedAt).getTime()
  );
}
```

### 收藏筛选

在 Projects 页面顶部区域（搜索栏附近），添加一个筛选按钮或 Tab，用于切换「全部 / 已收藏」视图：

```tsx
<div className="flex items-center gap-2 mb-4">
  <button
    className={`px-3 py-1.5 text-xs rounded-md transition-colors ${
      filter === 'all'
        ? 'bg-primary text-primary-foreground'
        : 'text-muted-foreground hover:text-foreground hover:bg-muted'
    }`}
    onClick={() => setFilter('all')}
  >
    All
  </button>
  <button
    className={`px-3 py-1.5 text-xs rounded-md transition-colors ${
      filter === 'favorites'
        ? 'bg-primary text-primary-foreground'
        : 'text-muted-foreground hover:text-foreground hover:bg-muted'
    }`}
    onClick={() => setFilter('favorites')}
  >
    ★ Favorites
  </button>
</div>
```


## 九、实现顺序

按以下顺序执行，每步完成后应该是可运行状态：

**Step 1: 数据模型 + Mock 数据**
- 给 Project 接口添加 `isFavorite`、`memberCount`、`canvasCount`、`hasActiveContainer` 字段

**Step 2: 脉搏灯样式**
- 在全局 CSS 中添加 `@keyframes pulse-glow` 和 `.pulse-dot` 样式

- 标题行包含：脉搏灯（条件渲染）+ 标题 + 收藏星标

**Step 4: Grid 布局调整**
- `minmax(320px)` → `minmax(200px)`
- `gap-4` → `gap-3`

**Step 5: 排序与筛选**
- 默认按更新时间降序
- 添加 All / Favorites 筛选按钮

**Step 6: Project Detail 页面**
- 添加 `/project/:id` 路由
- 实现 ProjectDetail 组件（顶部栏 + 项目信息 + Canvas 列表）
- 实现 CanvasCard 组件

## 十、重要提醒

- 使用现有 design tokens（`bg-card`、`bg-background`、`text-foreground`、`text-muted-foreground`、`border-border`、`bg-muted`、`bg-primary`、`text-primary-foreground`），不要硬编码颜色
- 唯一的硬编码颜色是脉搏灯的 `#22c55e`（green-500），因为它需要在动画中使用
- 所有过渡动画保持微妙（150-200ms），使用 Tailwind `transition-all` 或 `transition-colors`
- Grid 响应式：移动端 1-2 列，平板 3 列，桌面 4-6 列，由 `auto-fill` + `minmax(200px)` 自动处理
- 收藏星标常驻显示，不是 hover 才出现
- 活容器的脉搏灯是唯一的动画元素，不要给其他元素加动画
