## 视觉统一原则

本次修正的核心设计约束：页面内所有容器元素使用同一套视觉语言。

**统一容器样式**：`rounded-lg border border-border bg-card`

| 元素 | 容器样式 | 状态区分方式 |
|------|---------|-------------|
| 状态条 | `border-border bg-card` + 左侧 3px 色条 | 色条颜色：绿/灰/红 |
| Canvas 卡片 | `border-border bg-card` | hover 时 `border-primary/40` |

不再使用彩色背景（`bg-green-500/5`）区分状态条，改用左侧色条。这样状态条和 Canvas 卡片视觉上属于同一家族。

## 一、页面布局修正（新增）

### 问题

当前 Detail 页面内容区域被限制在一个窄居中列（类似 `max-w-2xl mx-auto`），两侧各有约 25-30% 的空白。对于"项目指挥中心"页面，这不合理：

- 内容区像博客文章而不是工作台，信息密度低
- 返回按钮悬浮在页面中央，而非内容区左边缘
- Canvas 卡片网格被挤压，无法充分利用可用宽度
- 状态条也被压缩在窄列里，操作按钮区域局促

### 参考

Linear、Notion、GitHub 的项目详情页：内容填满 sidebar 右侧的可用宽度，只留合理 padding（24-32px）。不使用窄居中列。

### 修正

找到 Project Detail 页面的最外层容器，移除窄居中约束，改为填满可用宽度：

```tsx
{/* 改前（大致） */}
<div className="max-w-2xl mx-auto px-4 py-6">
  {/* 页面内容 */}
</div>

{/* 改后 */}
<div className="w-full px-6 lg:px-8 py-6">
  {/* 页面内容 */}
</div>
```

### 关键要点

- 移除 `max-w-2xl mx-auto`（或 `max-w-3xl mx-auto`，取决于现有代码）
- 改为 `w-full px-6 lg:px-8`，内容自然填满 sidebar 右侧空间
- Canvas 卡片网格随宽度自适应：窄屏 2 列，宽屏可展示 3 列
- 不需要改 Canvas 卡片本身的样式，只改外层容器宽度约束

### Canvas 网格自适应（可选优化）

如果当前 Canvas 网格是固定 2 列，可改为响应式：

```tsx
<div className="grid grid-cols-2 lg:grid-cols-3 gap-4">
  {project.canvases?.map((canvas) => (
    <CanvasCard key={canvas.id} canvas={canvas} isActiveProject={isActiveProject} />
  ))}
</div>
```

宽屏 3 列让用户一眼看到更多 Canvas，减少滚动。

## 三、活容器状态条重设计

仅当 `project.hasActiveContainer === true` 时渲染。位于元信息行下方、Canvases 标题上方。

### 改前（Doc 58 实现）

状态条使用彩色背景（`bg-green-500/5`），和 Canvas 卡片的无背景边框风格不统一。

### 改后

状态条改为和 Canvas 卡片同样的 `border-border bg-card`，通过左侧 3px 色条区分状态。新增 `[⚙]` 管理入口。

```
┌──────────────────────────────────────────────────────────────┐
│▎● Running · Every 3d · Last: Feb 24    [Pause] [Run Now] [⚙]│
│▎"Competitor A updated pricing — new enterprise tier added"   │
└──────────────────────────────────────────────────────────────┘
```

### 数据结构（不变）

```typescript
type ContainerStatus = 'running' | 'paused' | 'error';

interface ActiveContainerInfo {
  status: ContainerStatus;
  frequency: string;
  lastRunAt: string;
  nextRunAt: string;
  lastSummary: string;
  errorMessage?: string;
}
```

### 状态条样式映射（修改）

```typescript
const statusStyles: Record<ContainerStatus, {
  barColor: string;    // 左侧色条颜色
  dotColor: string;
  label: string;
  labelColor: string;
}> = {
  running: {
    barColor: 'bg-green-500',
    dotColor: 'bg-green-500',
    label: 'Running',
    labelColor: 'text-green-400',
  },
  paused: {
    barColor: 'bg-muted-foreground/40',
    dotColor: 'bg-muted-foreground/40',
    label: 'Paused',
    labelColor: 'text-muted-foreground',
  },
  error: {
    barColor: 'bg-red-500',
    dotColor: 'bg-red-500',
    label: 'Error',
    labelColor: 'text-red-400',
  },
};
```

关键变化：移除 `bg` 和 `border` 字段，新增 `barColor`。所有状态共用 `border-border bg-card`。

### 组件实现（修改）

```tsx
function ActiveContainerStatusBar({
  container,
  onPause,
  onResume,
  onRunNow,
  onRetry,
  onOpenSettings,
}: {
  container: ActiveContainerInfo;
  onPause: () => void;
  onResume: () => void;
  onRunNow: () => void;
  onRetry: () => void;
  onOpenSettings: () => void;
}) {
  const style = statusStyles[container.status];

  return (
    <div
      className="relative rounded-lg border border-border bg-card
                 overflow-hidden mb-4"
      title={container.status === 'running'
        ? `Next run: ${formatDateTime(container.nextRunAt)}`
        : undefined}
    >
      {/* 左侧色条 */}
      <div className={`absolute left-0 top-0 bottom-0 w-[3px] ${style.barColor}`} />

      <div className="px-4 py-3 pl-5">
        {/* 第一行：状态 + 频率 + 上次执行 + 操作按钮 */}
        <div className="flex items-center justify-between">
          <div className="flex items-center gap-2 text-sm">
            <span className={`w-2 h-2 rounded-full ${style.dotColor} ${
              container.status === 'running' ? 'animate-pulse' : ''
            }`} />
            <span className={`font-medium ${style.labelColor}`}>
              {style.label}
            </span>
            {container.status !== 'error' && (
              <>
                <span className="text-muted-foreground/40">·</span>
                <span className="text-muted-foreground/60">
                  {container.frequency}
                </span>
              </>
            )}
            <span className="text-muted-foreground/40">·</span>
            <span className="text-muted-foreground/60">
              {container.status === 'error'
                ? `Last attempt failed: ${formatDate(container.lastRunAt)}`
                : `Last: ${formatDate(container.lastRunAt)}`}
            </span>
          </div>

          {/* 操作按钮区 */}
          <div className="flex items-center gap-2">
            {/* 状态相关按钮（与 Doc 58 一致） */}
            {container.status === 'running' && (
              <>
                <button onClick={onPause}
                  className="px-2.5 py-1 text-xs text-muted-foreground
                             hover:text-foreground border border-border
                             rounded-md transition-colors">
                  Pause
                </button>
                <button onClick={onRunNow}
                  className="px-2.5 py-1 text-xs bg-green-500/20
                             text-green-400 hover:bg-green-500/30
                             rounded-md transition-colors">
                  Run Now
                </button>
              </>
            )}
            {container.status === 'paused' && (
              <>
                <button onClick={onResume}
                  className="px-2.5 py-1 text-xs text-muted-foreground
                             hover:text-foreground border border-border
                             rounded-md transition-colors">
                  Resume
                </button>
                <button onClick={onRunNow}
                  className="px-2.5 py-1 text-xs bg-primary/20 text-primary
                             hover:bg-primary/30 rounded-md transition-colors">
                  Run Now
                </button>
              </>
            )}
            {container.status === 'error' && (
              <button onClick={onRetry}
                className="px-2.5 py-1 text-xs bg-red-500/20 text-red-400
                           hover:bg-red-500/30 rounded-md transition-colors">
                Retry
              </button>
            )}

            {/* 管理入口 — 新增 */}
            <button
              onClick={onOpenSettings}
              className="p-1 text-muted-foreground/40
                         hover:text-muted-foreground
                         transition-colors rounded"
              title="Container settings"
            >
              <SettingsIcon className="w-3.5 h-3.5" />
            </button>
          </div>
        </div>

        {/* 第二行：变化摘要 */}
        <p className={`text-sm mt-1.5 ${
          container.status === 'paused'
            ? 'text-muted-foreground/40'
            : 'text-muted-foreground'
        }`}>
          {container.status === 'error'
            ? container.errorMessage
            : `"${container.lastSummary}"`}
        </p>
      </div>
    </div>
  );
}
```

### 关键变化说明

与 Doc 58 的差异：

| 项目 | Doc 58 | 本次 |
|------|--------|------|
| 外层容器 | `${style.bg} border ${style.border}` | `border-border bg-card` 统一样式 |
| 状态区分 | 整个背景色变化 | 左侧 3px 色条（`absolute left-0`） |
| 内边距 | `px-4 py-3` | `px-4 py-3 pl-5`（左侧留出色条空间） |
| 管理入口 | 无 | 新增 `[⚙]` 齿轮按钮 |
| 操作按钮 | Pause/Resume/Run Now/Retry | 不变，仅新增齿轮 |

## 四、活容器管理弹窗（新增）

点击状态条右侧 `[⚙]` 齿轮按钮打开。使用 Radix UI Dialog 实现。

### 弹窗结构

```
┌─ Container Settings ──────────────────────────────┐
│                                                    │
│  Frequency                                         │
│  ┌──────────────────────────────────┐              │
│  │ Every 3 days                   ▾ │              │
│  └──────────────────────────────────┘              │
│                                                    │
│  Estimated Cost                                    │
│  ~50 tokens per run · ~500 tokens/month            │
│                                                    │
│  Monitoring Target                                 │
│  competitor-a.com/pricing                          │
│  competitor-b.com/features                         │
│  (Configured in AIChat)                            │
│                                                    │
│  ─────────────────────────────────────             │
│  [Stop Monitoring]                                 │
│                                                    │
└────────────────────────────────────────────────────┘
```

### 数据结构

```typescript
interface ContainerSettings {
  frequency: string;
  estimatedTokensPerRun: number;
  monitoringTargets: string[];  // URL 列表
}
```

### 频率选项

```typescript
const frequencyOptions = [
  { value: 'daily', label: 'Every day' },
  { value: 'every_3_days', label: 'Every 3 days' },
  { value: 'weekly', label: 'Every week' },
  { value: 'biweekly', label: 'Every 2 weeks' },
];
```

### 组件实现

```tsx
function ContainerSettingsDialog({
  open,
  onOpenChange,
  settings,
  onUpdateFrequency,
  onStopContainer,
}: {
  open: boolean;
  onOpenChange: (open: boolean) => void;
  settings: ContainerSettings;
  onUpdateFrequency: (frequency: string) => void;
  onStopContainer: () => void;
}) {
  const [showStopConfirm, setShowStopConfirm] = useState(false);

  const monthlyEstimate = Math.round(
    settings.estimatedTokensPerRun * getRunsPerMonth(settings.frequency)
  );

  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent className="sm:max-w-md">
        <DialogHeader>
          <DialogTitle className="text-base font-semibold">
            Container Settings
          </DialogTitle>
        </DialogHeader>

        <div className="space-y-5 py-2">
          {/* 频率设置 */}
          <div>
            <label className="text-xs font-medium text-muted-foreground
                              uppercase tracking-wide mb-1.5 block">
              Frequency
            </label>
            <select
              value={settings.frequency}
              onChange={(e) => onUpdateFrequency(e.target.value)}
              className="w-full rounded-md border border-border bg-card
                         px-3 py-2 text-sm text-foreground"
            >
              {frequencyOptions.map((opt) => (
                <option key={opt.value} value={opt.value}>
                  {opt.label}
                </option>
              ))}
            </select>
          </div>

          {/* 成本预估 */}
          <div>
            <label className="text-xs font-medium text-muted-foreground
                              uppercase tracking-wide mb-1.5 block">
              Estimated Cost
            </label>
            <p className="text-sm text-foreground">
              ~{settings.estimatedTokensPerRun} tokens per run
              <span className="text-muted-foreground/60">
                {' '}· ~{monthlyEstimate} tokens/month
              </span>
            </p>
          </div>

          {/* 监控目标 */}
          <div>
            <label className="text-xs font-medium text-muted-foreground
                              uppercase tracking-wide mb-1.5 block">
              Monitoring Targets
            </label>
            <div className="space-y-1">
              {settings.monitoringTargets.map((url, i) => (
                <p key={i} className="text-sm text-foreground truncate">
                  {url}
                </p>
              ))}
            </div>
            <p className="text-xs text-muted-foreground/50 mt-1">
              Configured in AIChat
            </p>
          </div>

          {/* 分隔线 + 停止按钮 */}
          <div className="border-t border-border pt-4">
            {!showStopConfirm ? (
              <button
                onClick={() => setShowStopConfirm(true)}
                className="text-sm text-red-400 hover:text-red-300
                           transition-colors"
              >
                Stop Monitoring
              </button>
            ) : (
              <div className="space-y-2">
                <p className="text-xs text-muted-foreground">
                  This will permanently stop the container.
                  You can create a new one from AIChat.
                </p>
                <div className="flex gap-2">
                  <button
                    onClick={() => {
                      onStopContainer();
                      onOpenChange(false);
                    }}
                    className="px-3 py-1.5 text-xs bg-red-500/20
                               text-red-400 hover:bg-red-500/30
                               rounded-md transition-colors"
                  >
                    Confirm Stop
                  </button>
                  <button
                    onClick={() => setShowStopConfirm(false)}
                    className="px-3 py-1.5 text-xs text-muted-foreground
                               hover:text-foreground border border-border
                               rounded-md transition-colors"
                  >
                    Cancel
                  </button>
                </div>
              </div>
            )}
          </div>
        </div>
      </DialogContent>
    </Dialog>
  );
}
```

function getMockContainerSettings(): ContainerSettings {

function getRunsPerMonth(frequency: string): number {
  const map: Record<string, number> = {
    daily: 30,
    every_3_days: 10,
    weekly: 4,
    biweekly: 2,
  };
  return map[frequency] ?? 10;
}

### Bug 2 + 3: 卡片底部日期丢失

红点和日期被实现为互斥分支。修正为：日期始终渲染，红点作为可选前缀。

### 修正后的完整 CanvasCard 组件

```tsx
function CanvasCard({
  canvas,
  isActiveProject,
}: {
  canvas: Canvas;
  isActiveProject: boolean;
}) {
  return (
    <div
      className="rounded-lg border border-border bg-card p-4
                 hover:border-primary/40 hover:shadow-sm
                 cursor-pointer transition-all"
      onClick={() => navigate(`/canvas/${canvas.id}`)}
    >
      {/* 标题 */}
      <div className="flex items-center gap-2 mb-2">
        <span className="text-sm">🎨</span>
        <h3 className="text-sm font-medium text-foreground truncate">
          {canvas.title}
        </h3>
      </div>

      {/* 描述 */}
      <p className="text-xs text-muted-foreground line-clamp-2 mb-3">
        {canvas.description}
      </p>

      {/* 内容量指标 — 所有项目都显示 */}
      <div className="text-xs text-muted-foreground/50">
        {canvas.cardCount} {canvas.cardCount === 1 ? 'card' : 'cards'} · {canvas.shotCount} {canvas.shotCount === 1 ? 'shot' : 'shots'}
      </div>

      {/* 更新日期 — 始终显示，红点为可选前缀 */}
      <div className="flex items-center gap-1.5 mt-1">
        {isActiveProject && canvas.hasNewUpdates && (
          <span className="w-1.5 h-1.5 rounded-full bg-red-500 shrink-0" />
        )}
        <span className={`text-xs ${
          isActiveProject && canvas.hasNewUpdates
            ? 'text-red-400'
            : 'text-muted-foreground/40'
        }`}>
          Updated {formatDate(canvas.updatedAt)}
        </span>
      </div>
    </div>
  );
}
```

### 关键修正逻辑

- `Updated {date}` 始终渲染，不受任何条件控制
- 红点仅在 `isActiveProject && canvas.hasNewUpdates` 时渲染
- 有红点时日期文字变红（`text-red-400`），无红点时灰色（`text-muted-foreground/40`）
- 普通项目即使 mock 数据中 `hasNewUpdates=true`，因为 `isActiveProject=false`，红点不会显示
