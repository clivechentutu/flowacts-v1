# Home页面案例展示区优化方案

## 一、设计目标

**目的：** 让用户直观看到最终能得到什么样的产出物

**核心价值：**
- 展示Canvas报告的质量和形式
- 降低用户对"这东西能干嘛"的疑虑
- 通过真实案例建立信任

---

## 三、案例内容

### 3.1 推荐展示的案例

| 案例  | 标题                             | 描述                                                                    | 截图内容           |
| --- | ------------------------------ | --------------------------------------------------------------------- | -------------- |
| 1   | Competitor Onboarding Analysis | Analyzed Notion's 5-step signup flow, identified 3 UX friction points | 展示注册流程截图+标注+洞察 |
| 2   | Pricing Page Comparison        | Compared Stripe vs Square pricing strategies with visual breakdown    | 展示定价页面对比+分析    |
| 3   | E-commerce UX Audit            | Audited checkout flow with 12 actionable insights                     | 展示购物流程截图+问题标注  |

### 3.2 案例截图要求

**截图内容应展示：**
- Canvas画布的整体布局
- 截图卡片（带标注）
- AI生成的洞察文本
- 清晰的视觉层次

**截图尺寸：**
- 推荐比例：16:9 或 4:3
- 最小宽度：400px
- 建议使用高质量PNG

### 4.2 案例卡片组件

```jsx
function CaseStudyCard({ icon, title, description, image, link }) {
  return (
    <div className="case-card rounded-xl border border-border bg-card overflow-hidden hover:shadow-lg transition-shadow">
      {/* 截图区域 */}
      <div className="aspect-video bg-muted overflow-hidden">
        <img
          src={image}
          alt={title}
          className="w-full h-full object-cover hover:scale-105 transition-transform duration-300"
        />
      </div>

      {/* 内容区域 */}
      <div className="p-4">
        <h3 className="font-semibold text-base mb-2 flex items-center gap-2">
          <span>{icon}</span>
          <span>{title}</span>
        </h3>
        <p className="text-sm text-muted-foreground leading-relaxed">
          {description}
        </p>
        {link && (
          <a
            href={link}
            className="inline-flex items-center gap-1 text-sm text-primary mt-3 hover:underline"
          >
            View Report
            <span>→</span>
          </a>
        )}
      </div>
    </div>
  );
}
```

### 4.3 案例展示区组件

```jsx
function CaseStudiesSection() {
  return (
    <section className="py-16 bg-muted/20">
      <div className="container mx-auto px-4">
        {/* 标题 */}
        <div className="text-center mb-10">
          <h2 className="text-2xl md:text-3xl font-bold mb-2">
            See what you'll get
          </h2>
          <p className="text-muted-foreground">
            Real examples of AI team's work
          </p>
        </div>

        {/* 案例卡片网格 */}
        <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6 max-w-5xl mx-auto">
          {caseStudies.map((study) => (
            <CaseStudyCard
              key={study.id}
              icon={study.icon}
              title={study.title}
              description={study.description}
              image={study.image}
              link={study.link}
            />
          ))}
        </div>

        {/* 可选：查看更多按钮 */}
        <div className="text-center mt-10">
          <button className="px-6 py-3 rounded-lg border border-border hover:bg-muted transition-colors">
            View more examples
          </button>
        </div>
      </div>
    </section>
  );
}
```

## 五、交互设计

### 5.1 卡片交互

| 交互 | 效果 |
|------|------|
| **Hover卡片** | 添加阴影（shadow-lg） |
| **Hover截图** | 轻微放大（scale-105） |
| **点击卡片** | 跳转到详情页或打开Modal |
| **点击"View Report"** | 跳转到完整报告 |

### 5.2 响应式布局

| 屏幕尺寸 | 布局 |
|----------|------|
| **Mobile (<768px)** | 单列，卡片全宽 |
| **Tablet (768-1024px)** | 两列 |
| **Desktop (>1024px)** | 三列 |

- 作为展示用途
