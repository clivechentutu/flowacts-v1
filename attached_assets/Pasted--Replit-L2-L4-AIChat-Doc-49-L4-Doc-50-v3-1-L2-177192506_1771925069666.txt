# Replit 指令：L2 与 L4 图标调整

> 仅调整 AIChat 输入区域的图标，其他所有功能、样式、布局不变
> 关联决策：Doc 49（L4 精简）、Doc 50 v3.1（L2 格式体系）

---

## 变更范围

只改两个地方：
1. **L2 输出格式行**（输入框内顶部的格式图标）
2. **L4 功能图标行**（输入框内底部的操作图标）

其他所有内容（L1 上下文条、L3 文本输入区、Placeholder、样式、布局、交互逻辑）完全不动。

---

## 一、L2 输出格式行

### 改前

```
📄  📊  🧠  📋  📑
```

5 个图标：Document / Table / Mind Map / Outline / Report

### 改后

```
📄  📊  🏆  🧠
```

4 个图标：Document / Table / Scorecard / Mind Map

### 具体操作

1. 找到输出格式图标的数据定义（数组/配置），通常类似：

```jsx
const outputFormats = [
  { icon: "📄", label: "Document", value: "document" },
  { icon: "📊", label: "Table", value: "table" },
  { icon: "🧠", label: "Mind Map", value: "mindmap" },
  { icon: "📋", label: "Outline", value: "outline" },
  { icon: "📑", label: "Report", value: "report" },
];
```

2. 替换为：

```jsx
const outputFormats = [
  { icon: "📄", label: "Document", value: "document" },
  { icon: "📊", label: "Table", value: "table" },
  { icon: "🏆", label: "Scorecard", value: "scorecard" },
  { icon: "🧠", label: "Mind Map", value: "mindmap" },
];
```

变化说明：
- 删除 `📋 Outline` 和 `📑 Report`
- 新增 `🏆 Scorecard`（插在 Table 和 Mind Map 之间）
- `🧠 Mind Map` 移到最后

### 注意

- 交互逻辑不变（点击选中/取消、多选、hover tooltip）
- 如果有 tooltip 文案，Scorecard 的 tooltip 为 "Scorecard"
- Home 和 Studio 两个变体都要改（它们应该共用同一份数据）

## 二、L4 功能图标行

### 改前

```
📎  @  ⚡  🌐  │  Fast      [→ 发送]
```

或 Studio 版本：

```
📎  @  ⚡  🌐              [↗ 发送]
```

### 改后（Home 和 Studio 统一）

```
📎  ⚡                      [→ 发送]
```

### 具体操作

1. 找到功能图标行的组件/数据定义

2. 删除以下元素：
   - `@` 提及图标（整个按钮/图标移除）
   - `🌐` Web 图标（整个按钮/图标移除）
   - `│` 分隔线（如果有的话）
   - `Fast` 模式开关（整个 toggle/按钮移除）

3. 保留：
   - `📎` 附件图标（位置不变，仍在最左）
   - `⚡` 快捷操作图标（紧跟 📎 之后）
   - `→` 发送按钮（位置不变，仍在最右）

4. 如果 Studio 的发送按钮是 `↗`，统一改为 `→`

### 注意

- 📎 和 ⚡ 的点击行为完全不变
- 发送按钮的功能完全不变，只统一图标为 `→`
- Home 和 Studio 两个变体都要改
- 如果 `@` 功能有绑定到输入框的 `@` 字符触发逻辑，那个保留不动（只移除图标按钮）

## 五、V1 阶段 L2 扩展

> 当进入 V1 阶段时执行。MVP 阶段不动。

### 改前（MVP 状态）

```
📄  📊  🏆  🧠
```

### 改后

```
📄  📊  🏆  🧠  📈  ⏱
```

6 个图标：+Chart / +Timeline

### 具体操作

在 `outputFormats` 数组末尾追加两项：

```jsx
const outputFormats = [
  { icon: "📄", label: "Document", value: "document" },
  { icon: "📊", label: "Table", value: "table" },
  { icon: "🏆", label: "Scorecard", value: "scorecard" },
  { icon: "🧠", label: "Mind Map", value: "mindmap" },
  { icon: "📈", label: "Chart", value: "chart" },         // V1 新增
  { icon: "⏱", label: "Timeline", value: "timeline" },    // V1 新增
];
```

同时将 Mind Map 的渲染从缩进文本升级为可视化思维导图（Markmap 或类似库）。

### 注意

- 原有 4 个格式的顺序、图标、交互完全不变
- 只在末尾追加，不插入中间
- L4、L1、L3 全部不动

## 六、V2 阶段 L2 扩展

> 当进入 V2 阶段时执行。V1 之前不动。

### 改前（V1 状态）

```
📄  📊  🏆  🧠  📈  ⏱
```

### 改后

```
📄  📊  🏆  🧠  📈  ⏱  [+]
```

9 个格式，超过 7 个上限，启动溢出机制。L2 行显示前 6 个 + `[+]` 按钮。

### 具体操作

1. 在 `outputFormats` 数组末尾追加三项：

```jsx
const outputFormats = [
  // ... 前 6 个不变 ...
  { icon: "🔀", label: "Flowchart", value: "flowchart" },       // V2 新增
  { icon: "🎬", label: "Slides", value: "slides" },             // V2 新增
  { icon: "🎨", label: "Infographic", value: "infographic" },   // V2 新增
];
```

2. L2 行渲染逻辑改为：
   - 如果格式总数 ≤ 7：全部平铺显示
   - 如果格式总数 > 7：显示前 6 个 + `[+]` 按钮，点击 `[+]` 展开完整格式面板
   - 用户可自定义哪 6 个显示在 L2 行中（类似浏览器书签栏）

### 注意

- 原有 6 个格式的顺序、图标、交互完全不变
- `[+]` 按钮的样式与格式图标一致（同尺寸、同间距），但视觉上有区分（如灰色/虚线边框）
- L4、L1、L3 全部不动
