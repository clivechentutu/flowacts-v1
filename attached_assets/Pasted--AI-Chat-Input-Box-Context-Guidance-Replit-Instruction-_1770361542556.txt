# AI Chat Input Box Context Guidance — Replit Instruction

> Add context-aware suggestion chips above the input box, make the placeholder text dynamic based on task state, and add tooltips to all toolbar icons. No backend changes — use mock state to demonstrate the three scenarios.

---

## Current State

The Chat input area currently shows:
```
┌──────────────────────────────────────┐
│ Ask Upliftly to analyze a flow...   │
│ 📎  @  ⚡  ⓘ        🌐  ➤         │
└──────────────────────────────────────┘
```

Problems:
- Static placeholder regardless of task state
- Toolbar icons have no tooltips — users don't know what they do
- No suggested actions — users (especially new ones) don't know what to type

---

## What to Change

Three changes to the Chat input area:

1. **Context Suggestion Chips** above the input box
2. **Dynamic placeholder** text based on task state
3. **Tooltips** on all toolbar icons

---

## Change 1: Context Suggestion Chips

### Design

Add a row of clickable suggestion chips **above** the input box, **below** the conversation:

```
┌──────────────────────────────────────┐
│         [conversation area]          │
│                                      │
│ [Compare with competitor B]          │
│ [Focus on pricing page]             │
│ [Generate report]                    │
├──────────────────────────────────────┤
│ Ask a follow-up or redirect...      │
│ 📎  @  ⚡  ⓘ        🌐  ➤         │
└──────────────────────────────────────┘
```

### Three Scenarios (use mock state to switch)

**Scenario 1: Empty project (no messages yet)**
```js
const CHIPS_EMPTY = [
  "Analyze competitor.com signup flow",
  "Compare two products' pricing",
  "Audit my landing page UX",
];
```

**Scenario 2: Task in progress (AI is working)**
```js
const CHIPS_IN_PROGRESS = [
  "Focus on the pricing page",
  "Skip to the signup flow",
  "Take a screenshot here",
];
```

**Scenario 3: Task completed (results delivered)**
```js
const CHIPS_COMPLETED = [
  "Compare with another competitor",
  "Generate a report",
  "Dig deeper into signup friction",
];
```

### SuggestionChips Component

```jsx
function SuggestionChips({ chips, onSelect }) {
  if (!chips || chips.length === 0) return null;

  return (
    <div className="flex flex-wrap gap-2 px-4 py-2">
      {chips.map((chip, i) => (
        <button
          key={i}
          onClick={() => onSelect(chip)}
          className="rounded-full px-3 py-1.5 text-xs
            bg-muted/50 hover:bg-muted
            text-muted-foreground hover:text-foreground
            border border-border/50 hover:border-border
            transition-colors cursor-pointer"
        >
          {chip}
        </button>
      ))}
    </div>
  );
}
```

### Behavior

- Clicking a chip fills the input box with the chip text and auto-sends it (simulating a user message)
- After clicking, the chips update to the next scenario's set
- Maximum 3-4 chips visible at a time
- Chips sit in a `flex-wrap` container — if they overflow, they wrap to a second line

## Change 2: Dynamic Placeholder

### Rules

The input box placeholder changes based on task state:

| Task State | Placeholder Text |
|-----------|-----------------|
| `empty` (no messages) | `"Paste a URL or describe what you'd like to analyze..."` |
| `in_progress` (AI working) | `"Ask a follow-up or redirect the analysis..."` |
| `completed` (results done) | `"Compare, dig deeper, or generate a report..."` |
| `thinking` (AI processing) | `"Type to redirect or wait for results..."` |

### Implementation

```jsx
function getPlaceholder(taskState) {
  switch (taskState) {
    case "empty":
      return "Paste a URL or describe what you'd like to analyze...";
    case "in_progress":
      return "Ask a follow-up or redirect the analysis...";
    case "completed":
      return "Compare, dig deeper, or generate a report...";
    case "thinking":
      return "Type to redirect or wait for results...";
    default:
      return "Ask Upliftly to analyze a flow...";
  }
}
```

For the demo, use the `in_progress` state as default (matching the current mock conversation).
