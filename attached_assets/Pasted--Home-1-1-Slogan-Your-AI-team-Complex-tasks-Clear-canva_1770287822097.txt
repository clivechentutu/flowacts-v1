## 三、Quick Start任务场景（标签/Chips形式）

### 3.1 标签内容

| 图标 | 标签文案 | 点击后填充的Prompt |
|------|----------|-------------------|
| 🔍 | Onboarding Analysis | "Walk through the signup and onboarding flow of [competitor.com], identify UX strengths and friction points." |
| 💰 | Pricing Comparison | "Compare the pricing pages of [company A] and [company B], analyze their pricing strategies and positioning." |
| 🎯 | UX Audit | "Audit the user experience of [website.com], focusing on navigation, clarity, and conversion paths." |
| 📊 | Feature Comparison | "Compare the feature sets of [product A] and [product B], create a visual comparison." |
| 📱 | Mobile UX | "Explore the mobile experience of [website.com], test responsiveness and mobile interactions." |

### 3.2 标签样式

```jsx
// 标签组件
<button
  onClick={() => setInputValue(prompt)}
  className="px-4 py-2 rounded-full bg-muted hover:bg-muted/80 text-sm transition-colors flex items-center gap-2 border border-border/50"
>
  <span>{icon}</span>
  <span>{label}</span>
</button>
```

**样式说明：**
- 圆角：`rounded-full`（药丸形状）
- 背景：`bg-muted`
- 悬停：`hover:bg-muted/80`
- 边框：`border border-border/50`（微妙边框）
- 内边距：`px-4 py-2`
- 字体：`text-sm`

## 四、Replit实现代码

### 4.1 任务场景数据

```jsx
const quickStartScenarios = [
  {
    icon: "🔍",
    label: "Onboarding Analysis",
    prompt: "Walk through the signup and onboarding flow of [competitor.com], identify UX strengths and friction points."
  },
  {
    icon: "💰",
    label: "Pricing Comparison",
    prompt: "Compare the pricing pages of [company A] and [company B], analyze their pricing strategies and positioning."
  },
  {
    icon: "🎯",
    label: "UX Audit",
    prompt: "Audit the user experience of [website.com], focusing on navigation, clarity, and conversion paths."
  },
  {
    icon: "📊",
    label: "Feature Comparison",
    prompt: "Compare the feature sets of [product A] and [product B], create a visual comparison."
  },
  {
    icon: "📱",
    label: "Mobile UX",
    prompt: "Explore the mobile experience of [website.com], test responsiveness and mobile interactions."
  }
];
```

### 4.2 Quick Start区域组件

```jsx
function QuickStartSection({ onSelect }) {
  return (
    <div className="flex flex-wrap justify-center gap-2 mt-4">
      {quickStartScenarios.map((scenario, index) => (
        <button
          key={index}
          onClick={() => onSelect(scenario.prompt)}
          className="px-4 py-2 rounded-full bg-muted hover:bg-muted/80 text-sm transition-colors flex items-center gap-2 border border-border/50"
        >
          <span>{scenario.icon}</span>
          <span>{scenario.label}</span>
        </button>
      ))}
    </div>
  );
}
```
